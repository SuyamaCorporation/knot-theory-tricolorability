# 結び目理論 3彩色可能性 チェッカー（位相幾何学教育）

結び目図の3彩色可能性をルーフアフミン行列の行列式で判定する位相幾何学教育ツール。

## 機能

- 自明な結び目 / 三葉結び目 / 8の字結び目 / 五葉結び目等 7種のプリセット
- ルーフアフミン（Fox）行列の自動構築と表示（各交差の係数: 2, -1, -1）
- 縮小行列の行列式を計算し det mod 3 = 0 で3彩色可能性を判定
- Canvas による結び目模式図（アーク着色ビジュアライズ）
- JSON形式の交差情報を手動入力して任意結び目を判定可能
- 主要結び目の行列式・3彩色可否一覧テーブル

## 技術メモ

- Fox行列: 各交差 c_i で a_{over}=+2, a_{under1}=a_{under2}=-1、それ以外=0
- 縮小行列 = (n-1)×(n-1) の部分行列（最終行・列を除去）
- 行列式は整数ガウス消去法で計算
- 3彩色可能 ⟺ |det| mod 3 = 0 かつ |det| > 0
- 単体 HTML + Tailwind CDN
